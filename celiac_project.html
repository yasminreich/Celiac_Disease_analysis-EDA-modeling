Celiac Disease Lab Data — EDA + Modeling

Project Overview

The goal of this project is to explore and model laboratory and clinical data related to celiac disease.
Using a Kaggle dataset, the following steps were performed: - Exploratory data analysis (EDA)
- Feature engineering and data cleaning
- Supervised learning using: - Decision trees (C5.0)
- k-nearest neighbors (KNN)
- Random forest

A key clinical motivation is minimizing false negatives, since missing a true celiac diagnosis may lead to delayed treatment and long-term complications.

Data Source

The dataset was obtained from Kaggle:
Celiac Disease Lab Data
https://www.kaggle.com/datasets/jackwin07/celiac-disease-coeliac-disease

To ensure balanced class representation, the dataset was shuffled and subsampled to include an equal number of diagnosed and non-diagnosed individuals.
This processed dataset was saved and reused to ensure reproducibility.

Data Preparation

To ensure a balanced dataset, the original Kaggle data was:

  1. Shuffled randomly
  2. Subsampled to include:
    • 363 diagnosed patients
    • 363 non-diagnosed patients
  3. Cleaned to standardize categorical fields (e.g., Marsh score, diabetes type)

Feature Engineering

To prepare the data for modeling, the following transformations were applied:

  • Marsh scores were converted into numeric form
  • Binary clinical symptoms were encoded as 0/1
  • Gender and diagnosis variables were binarized
  • Variables with extensive missing values or redundant information were excluded

These steps ensured compatibility with correlation analysis and machine learning models.

#random forest: To improve upon the limitations of a single decision tree.

  • Reduced overfitting
  • Improved generalization
  • Built-in feature importance
# create random forest model
rf_mod <- 
  rand_forest(trees = 1000) %>% 
  set_engine("ranger") %>%   # engine - method of estimation the model will use
  set_mode("classification")
set.seed(234)
rf_fit <- 
  rf_mod %>% 
  fit(c_train_labels ~ ., data = c_train)

The accuracy of the training set was quite high, possibly even overly so. Therefore, we proceeded to assess the accuracy on the test set.

rf_testing_pred <- 
  predict(rf_fit, c_test) %>% 
  bind_cols(predict(rf_fit, c_test, type = "prob")) %>% 
  bind_cols(Label = c_test_labels)

# Accuracy calculation
rf_testing_pred %>%                   # test set predictions
  accuracy(truth = Label, .pred_class)

Model Comparison and Conclusions

Across all evaluated models:

  • The decision tree was interpretable but underperformed
  • KNN achieved moderate performance
  • The random forest achieved the best overall accuracy and ROC performance

Most importantly, the random forest substantially reduced false negatives,
making it the most clinically appropriate model for this task.
